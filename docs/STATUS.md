# 项目简要现状

更新日期：2026-10-22。

## 已完成

- 基于原A5程序独立迁移A1；原SH工作区保留，原仓库未改动。
- 视觉大写字母2-back，鼠标左键和空格均可响应；通知期间字母任务持续运行。
- 默认接入用户提供的18条通知材料及原始PNG，原XLSX、ZIP已归档，提供可重复导入脚本。默认18通知＋2对照，也保留快速预演和12条子集。
- 支持Mock及独立A1安卓图片显示端。后台“准备与检查”可扫描/绑定设备、打开显示端、重连、启动scrcpy、预览并手动发送图片、查看设备回执。
- 图片预传与双端哈希核对，双眼绘制/隐藏回执，请求去重；结果未知不自动重发。正式通知固定4秒，手动调试独立记录。
- SQLite快照、原始事件、浏览器待上传队列及ZIP导出。主试可从手机扫码进入后台，电脑运行被试页面。

## 已有验证

上一轮完成：9项设备链路自动检查通过，TypeScript检查通过，Android构建和lint通过，APK运行依赖及签名检查通过。桌面检查页的设备扫描、图片选择预览、无设备禁止发送已检查，未发现浏览器控制台错误。本次整理文档并提交，没有重复运行测试。

## 尚未完成

- 当前ADB无设备，尚未验收实际USB重连、镜内双眼图片、scrcpy画面及长时间稳定性。需要安装独立A1 APK，原A5文字APK不能接收图片。
- 安卓与浏览器时钟映射尚未完成；真机真实曝光前/中/后窗口为unknown，不能把请求发送时间作为实际呈现时间，也暂不能据此输出正式通知效应。Mock按浏览器时钟计算。
- 正式被试间顺序平衡、复述人工信息单元评分、跨被试分析及A2流程仍待实现。
- 来源材料3N-2L-05的单元标签为N1/N3/N4，已保留并标注差异，未擅自修改研究编码。

## 使用入口

需要Node.js 24+，仓库根执行`npm ci`、`npm start`，打开`http://127.0.0.1:5189/admin`。默认Mock，未连接设备不阻止启动；真机会话要求显示端就绪，不自动降级Mock。
