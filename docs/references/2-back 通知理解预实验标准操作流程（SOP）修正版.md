# 2\-back 通知理解预实验标准操作流程（SOP）修正版

核心变化：通知 trial 从“未定数量”固定为 12 个，按 3 轮 × 4 领域 排列；IU 数量为连续操纵变量（1/2/3），领域仅作材料背景；行数不强制匹配但必须记录、报告并在分析中作协变量处理。

## 实验前准备（每轮开始前完成）

### 2\.1 材料矩阵：12 条通知 = 4 领域 × 3 IU 水平

材料约束：

1. 每条通知 1–2 行；`line_count` 在 IU 切分之前锁定，不得根据切分结果反推行数。

2. 每条通知记录 `notification_id`、`domain`、`line_count`、`character_count`、`iu_count`。

3. 目标 IU 范围 1–3；出现 4 个 IU 的候选通知应删减或改写，不进入梯度。

4. 不强制行数与字数匹配；但预实验报告中必须报告 IU × 行数交叉表、IU 与 line\_count 的 Spearman 相关、IU 与 character\_count 的 Pearson 相关。

### 2\.2 IU 切分与定稿

1. 两名评分者独立按《语义信息单元操作手册》切分 12 条通知，为每个 IU 写一句“核心断言”。

2. 合议分歧：边界分歧倾向合并；定义分歧回到“可独立复述、可独立判定命中”标准。

3. 定稿 IU 清单，包含每个 IU 的编号、核心断言、原文起止位置。数据收集期间不再修改。

4. 记录切分信度：一致边界比例 ≥ 0\.80，kappa ≥ 0\.70；未达标通知重新合议或改写。

### 2\.3 应用型理解题

每条通知配一道 4 选 1 多选题，题干要求将通知信息应用于一个新情境，而非字面再认。题目难度由第二名研究者复核，避免与 IU 水平系统性混淆。预实验中理解题定位为补充/gate 指标，主因变量是复述。

### 2\.4 程序与设备检查

1. 显示器、键盘、录音设备（若口头复述）测试正常。

2. 配置文件包含：`pilot_round`、12 个通知 block 的 `notification_id`、控制 block 数、基线段/恢复段试次数、通知呈现时长、`effort_mode = dual_single_item`、`effort_format`、随机种子。

3. 运行测试 session，确认：

    - 通知期间无 2\-back 刺激；

    - `notification_onset`、`notification_offset`、`resumption_first_stimulus_onset` 写入日志；

    - 复述界面在恢复段后自动出现；

    - 通用努力题所有 block 后出现，情境化题仅通知 block 后出现；

    - 数据行包含 `line_count`、`character_count`、`iu_count`。

4. 清空测试数据，确认输出目录为空或已归档。

## 被试安排与知情同意

1. 每名被试单独施测，环境安静，主试位于侧后方。

2. 单 session 预计 35–45 分钟（含练习、12 通知 block、2–3 控制 block、休息、测量）。

3. 核对被试编号，登记年龄、性别、视力/矫正视力、神经/精神疾病史。

4. 签署知情同意书；说明可随时退出，数据匿名化。

5. 关闭或静音手机；确认坐姿和按键位置舒适。

## 指导语与练习

### 5\.1 指导语要点

1. 2\-back 规则：当前刺激与两个试次之前相同则按键，不同则不按键。

2. 通知：任务中可能出现 1–2 行通知；通知出现时正常阅读；通知消失后继续 2\-back。

3. 复述与理解题：每段任务后可能请复述通知内容，并回答一道关于通知含义的选择题；复述不要求逐字，尽可能完整；理解题不反馈对错。

4. 量表：每段任务后有一个心理努力评分；按真实感受评分。

5. 休息：block 间有休息，可按键提前结束，建议休息到提示再继续。

### 5\.2 练习 block

1. 运行 15–20 试次无通知 2\-back 练习。

2. 确认被试理解“两个试次之前”规则；必要时口头举例一次，不额外加练超过 1 个练习 block。

3. 练习数据标记 `practice`，不进入正式分析；练习后不施测量表，休息 30–60 s。

## 正式实验总体结构：3 轮 × 4 领域

12 个通知 block 分为 3 轮，每轮包含 4 个领域各 1 条通知，共 4 个通知 block。每轮内 4 个领域的顺序随机化；每轮结束后插入 1 个控制 block（若总控制 block 为 2 个，则第 1、2 轮后各 1 个，第 3 轮后不插）。

推荐顺序：

text

练习 → 休息第1轮：通知 block × 4（领域顺序随机）→ 控制 block 1 → 休息第2轮：通知 block × 4（领域顺序随机）→ 控制 block 2 → 休息第3轮：通知 block × 4（领域顺序随机）→ 控制 block 3（可选）→ 结束

IU 水平在轮次间的分配：每个领域在 3 轮中各出现一次，对应 IU = 1、2、3 各一次。具体哪一轮对应哪个 IU 水平，可在被试间通过 Latin square 平衡，或固定为“第 1 轮 IU=1、第 2 轮 IU=2、第 3 轮 IU=3”并在报告中说明。预实验阶段若被试数少，固定顺序更利于观察 IU 梯度；但需在报告中标注“IU 与轮次位置共变”的局限。

---

## 单个通知 block 操作细则

每个通知 block 按以下顺序执行：

text

基线段 20–25 试次（无通知）→ 通知窗口 3–5 s（自定步按键可提前结束）→ 恢复段 15–20 试次→ 延迟自由复述→ 应用型理解题（4 选 1）→ 通用任务努力量表→ 情境化恢复努力量表（仅通知 block）→ 休息 60–90 s

主试操作约束：

1. 基线段期间不干预、不提示；记录异常（走神、按键卡顿）但不打断。

2. 通知出现时保持安静，不指向屏幕、不解释内容。

3. 通知消失后恢复段立即开始，主试不提示“现在继续”。

4. 复述界面出现后不提供任何通知内容线索；被试询问时回答：“请尽可能回忆，不需要完全准确。”

5. 理解题不反馈对错；被试询问答案时回答：“实验结束后统一说明。”

6. 量表不解释“应该打多少分”；仅朗读锚点文字。

---

## 控制 block 操作细则

1. 控制 block 为连续 2\-back，长度与通知 block 总试次数匹配（35–45 试次），不插入通知。

2. block 结束后不施测复述与理解题，仅施测通用任务努力量表。

3. 控制 block 的作用是提供同时段无通知基线；主试不得额外插入提示或中断。

4. 若控制 block 仅 2 个，报告中注明“控制基线为全局近似，未按轮次完全匹配”。

---

## 复述、理解题与量表操作细则

### 9\.1 延迟自由复述

- 恢复段最后一个试次结束后自动出现，不插入额外延迟或固定延迟 ≤ 500 ms。

- 口头复述：启动录音，被试说完按键结束；事后按 IU 清单转写计分。

- 文本复述：被试键入，程序记录文本与键入时间。

- 计分：两名评分者独立判定每个 IU 的宽松命中与严格命中；记录绝对命中数 Hi*Hi* 和 ；错误添加单独记录，不扣减命中数。

- 报告复述计分信度（kappa 或 ICC）。

### 9\.2 应用型理解题

- 4 选 1，题干呈现与通知相关的新情境；被试按键选择。

- 记录选择、正确性、反应时；不反馈对错。

- 超时 30 s 未作答，主试可提示“请按直觉选择”，不提示内容。

- 预实验中作为补充/gate 指标：若复述出现大面积地板，理解题提供是否“至少加工到可应用”的判别信息。

### 9\.3 单题心理努力量表

- 通用任务努力：所有 block 后施测。题干：“完成刚才这段 2\-back 任务，你投入了多少心理努力？”

- 情境化恢复努力：仅通知 block 后追加。题干：“通知消失之后，为了重新回到 2\-back 任务的节奏并克服通知带来的干扰，你额外投入了多少心理努力？”

- 格式：RSME 0–150 或 Paas 9 点，按配置。

- 记录 `effort_type`、`effort_format`、`effort_rating`、`effort_start_time`、`effort_end_time`、`effort_duration_ms`。

- 控制 block 仅记录通用题。

## 数据管理与预实验专用输出

### 11\.1 必需数据文件

1. 逐试次数据：至少包含 `subject_id, pilot_round, block_index, block_type, notification_id, line_count, character_count, iu_count, trial_index_within_block, trial_index_global, stimulus, is_target, correct_response, participant_response, is_correct, rt_ms, stimulus_onset_time, stimulus_offset_time, notification_onset_time, notification_offset_time, notification_self_paced_offset, resumption_first_stim_onset_time, block_phase`。

2. 事件日志：单调时钟毫秒时间戳，记录 block\_start/end、notification\_onset/offset、self\_paced\_offset、resumption\_first\_stimulus\_onset、recall\_start/end、comprehension\_onset、effort\_start/end。

3. 复述评分附件：每个 `subject_id × notification_id` 一行，记录每个 IU 的宽松/严格命中、绝对命中数、%IU、错误添加数。

4. 理解题与量表数据：选择、正确性、反应时；通用/情境化努力评分与完成时长。

5. 配置快照：`pilot_round`、block 序列、通知映射、随机种子、`effort_mode`、`effort_format`、时长参数。

### 11\.2 快速摘要（session 结束自动生成）

必须包含：

- 每个 block 基线/恢复窗口正确率与 RT 均值；

- 基线 RT 被试内变异系数；

- 复述绝对命中数与 %IU 按 IU 水平（1/2/3）的均值与范围；

- IU × 行数交叉表；

- IU 与 line\_count 的 Spearman 相关、IU 与 character\_count 的 Pearson 相关；

- 理解题正确率；

- 通用与情境化努力评分均值、双题相关、平均完成时间；

- 通知未读完比例。
