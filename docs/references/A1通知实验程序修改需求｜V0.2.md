# A1通知实验程序修改需求｜V0\.2

**目标：** 保留连续视觉2\-back主任务，支持12个正式Trial（10个通知＋2个无通知对照），保证不同N水平的主任务刺激机会尽可能可比，并正确分析通知前、中、后表现。

## P0｜必须修改

- **试次编排**：支持12个正式Trial，其中10个通知、2个对照；N1/N2/N3按3/3/4、3/4/3、4/3/3跨被试轮换。

- **材料选择**：从每个N水平6条材料中抽取3或4条，单名被试内不重复；记录材料ID、N水平和业务类别。

- **呈现顺序**：不同N水平交错出现，2个对照Trial位置也需平衡，不能固定按N1→N2→N3依次完成。

- **2\-back序列检查**：生成完整计划后检查各N水平在Pre/During/Post阶段的目标数、非目标数、目标比例及目标位置分布。对明显失衡的计划提供警告，是否重新生成按预先冻结的规则决定。

- **时序参数化**：通知时长、SOA、刺激显示时间、Pre和Post长度均从配置读取，删除固定4秒通知所对应的硬编码。

- **阶段判定**：继续使用实际时间戳区分Pre/During/Post；跨越通知出现或消失边界的刺激单独标记。Post可进一步分为早期和后期。

- **统计方式**：增加按“被试×N水平×阶段”合并全部有效刺激计数后计算正确率、命中率、误报率及RT的功能。

- **缺失值处理**：没有目标时不计算命中率，没有正确命中时不计算命中RT，不以0代替。

- **质量控制**：保留随机种子、实际刺激序列、时间戳、异常标记和中断记录；真机时钟未校准时，不输出未经验证的通知期间表现。

## P1｜建议增加

- 增加命中率、误报率、平衡正确率、各指标有效分母，以及命中RT的均值、中位数与样本数。

- 增加Pre→During、Pre→Post早期、Pre→Post后期的变化比较。

- 输出被试×N水平×阶段汇总表、序列平衡检查表及完整Trial计划表。

- 关联每个Trial的理解题、自由复述、材料N单元和主任务表现。

- 增加材料编码、N单元标签及题目答案的预检提示。

- 在主试后台预览试次顺序、材料及序列平衡情况。

## 待Pilot确定

- 通知显示时间：8\.5秒为候选，不直接冻结。

- SOA：2000 ms与1500 ms比较后选择。

- Pre/Post：初步候选为约24秒/20秒。

- Post恢复分窗：初步考虑0–10秒与10–20秒。

- During是否足以支持独立的N水平统计分析，需检查有效目标数量。

- A/B文本形式的被试间或被试内安排，需与材料分配方案协调。

**验收重点：** 保证12个Trial数量正确、三个N水平材料分配正确、2\-back在通知期间不停顿、目标分布可审查，以及合并统计不再简单平均不同Trial的百分比。
