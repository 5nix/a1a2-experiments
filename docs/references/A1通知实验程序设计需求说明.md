# A1通知实验程序设计需求说明

## 系统概述

程序实现一个事件标记精确、时间戳完整、模块可配置的 2\-back 实验平台，支持控制 block 与通知嵌入 block，并在每个 block 后自动呈现理解测量与单题心理努力量表。程序需记录逐试次主任务数据、通知呈现锚点、理解测量结果与心理努力评分，支持预实验两轮迭代与快速摘要导出。

## 任务引擎

FR\-1 试次生成：按配置生成伪随机 2\-back 序列；目标比例 25–30%，连续相同刺激不超过 3 个；记录随机种子。

FR\-2 试次时间结构：刺激 500 ms，ISI 1,500 ms，单试次 2,000 ms，均可配置；反应窗口从刺激 onset 至下一刺激 onset 前；记录相对于刺激 onset 的 RT。

FR\-3 Block 类型：

- `control`：全程连续 2\-back，无通知；

- `notification`：基线段试次数（默认 20–25）→ 通知窗口 → 恢复段试次数（默认 15–20）。

FR\-4 反应采集：记录按键、RT、正确性（hit / miss / false alarm / correct rejection）；仅第一个有效按键作为反应。

## 通知模块

FR\-5 通知呈现：从外部文件加载 1–2 行通知；每个通知 block 对应一条通知；同一被试内不重复，被试间平衡。呈现时长默认 3–5 s，可配置。

FR\-6 通知锚点标记：写入 `notification_onset`、`notification_offset`、`resumption_first_stimulus_onset`，精度不低于 10 ms。

FR\-7 通知可见性：通知期间不呈现 2\-back 刺激或注视十字；通知消失后恢复段第一个刺激立即开始，或按配置的固定短间隔开始。

FR\-8 自定步阅读：通知界面提供按键（如空格），记录 `notification_self_paced_offset`；若未按键，在最长时限到达时自动消失。

## 理解测量模块

FR\-9 延迟自由复述：恢复段最后一个试次结束后自动呈现复述界面，不插入额外延迟或固定延迟 ≤ 500 ms；支持文本输入或录音提示两种模式；记录复述文本/录音文件名与完成时间。

FR\-10 应用型理解题：复述后呈现一道 4 选 1 多选题，题干与选项从外部文件加载，与通知配对；记录选择、正确性、反应时；题目要求将通知信息应用于新情境。

## 心理努力量表模块（修改重点）

FR\-11 量表模式：配置项 `effort_mode`，默认 `dual_single_item`。可选：

- `dual_single_item`：通用任务努力 \+ 情境化恢复努力；

- `single_general`：仅通用任务努力；

- `nasa_tlx_optional`：可选 NASA\-TLX/RTLX，不作为默认。

FR\-12 通用任务努力：每个 block 结束后、理解测量完成后施测，所有 block 均呈现。题干：“完成刚才这段 2\-back 任务，你投入了多少心理努力？”格式可配置：

- `RSME`：0–150 视觉模拟，九个锚点；

- `Paas_9pt`：9 点 Likert。

FR\-13 情境化恢复努力：仅通知 block 后施测，紧随通用题。题干：“通知消失之后，为了重新回到 2\-back 任务的节奏并克服通知带来的干扰，你额外投入了多少心理努力？”格式与通用题一致。

FR\-14 记录内容：每题记录 `effort_type`（general / recovery）、`effort_format`（RSME / Paas）、`effort_rating`、`effort_question_text`、`effort_start_time`、`effort_end_time`、`effort_duration_ms`。控制 block 仅记录 general。

FR\-15 可选 NASA\-TLX：若启用，记录各维度评分与完成时间；完整 TLX 的配对比较仅在首次施测或单一条件时使用，不在每个 block 后重复。

## Block 流程与休息

FR\-16 Block 序列：从配置文件读取 block 序列，包含类型、通知文件 ID、基线段/恢复段试次数；block 间休息默认 60–90 s，显示剩余时间，可按键提前结束。

FR\-17 练习 block：正式 block 前至少一个无通知 2\-back 练习 block，15–20 试次，数据不入正式分析。

## 数据记录

FR\-18 逐试次数据文件：至少包含：

text

subject\_id, pilot\_round, block\_index, block\_type, trial\_index\_within\_block,trial\_index\_global, stimulus, is\_target, correct\_response, participant\_response,is\_correct, rt\_ms, stimulus\_onset\_time, stimulus\_offset\_time,notification\_onset\_time, notification\_offset\_time, resumption\_first\_stim\_onset\_time,block\_phase \(baseline / notification / recovery / control\)

FR\-19 事件日志：按时间顺序记录 `block_start`、`block_end`、`notification_onset`、`notification_offset`、`notification_self_paced_offset`、`resumption_first_stimulus_onset`、`recall_start`、`recall_end`、`comprehension_question_onset`、`effort_start`、`effort_end`等，时间戳使用程序启动后的单调时钟毫秒值。

FR\-20 理解与量表数据文件：每个 block 一行，记录复述文本/录音文件名、复述完成时间、理解题选择与正确性、通用努力评分与时长、情境化努力评分与时长（仅通知 block）、可选 TLX 数据。

FR\-21 配置快照：每次运行保存实际生效配置，包括 `pilot_round`、block 序列、通知映射、随机种子、`effort_mode`、`effort_format`、时长参数。

## 预实验专用功能

FR\-22 轮次标记：配置 `pilot_round: round1 / round2`，写入所有数据文件。

FR\-23 快速摘要导出：session 结束后自动生成摘要，报告每个 block 基线/恢复窗口正确率与 RT 均值、基线 RT 变异系数、复述信息单元命中数、理解题正确率、通用与情境化努力评分均值及双题相关、量表平均完成时间。

FR\-24 通知阅读完成标记：记录自定步按键时间与是否超时，用于评估 3–5 s 暴露是否充分。
