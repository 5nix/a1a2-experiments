## 运行

仓库根目录执行 `npm start`，打开 `http://127.0.0.1:5189/admin`。后台创建会话后点击“在本机打开被试页面”。主试手机可扫描顶部二维码，电脑运行被试任务。被试任务需要至少1000×600的电脑窗口。

运行目录默认 `a1-notification-pilot/runtime/`，ZIP 落盘到 `a1-notification-pilot/exports/`；可通过 `A1_RUNTIME_DIR`、`A1_EXPORT_DIR` 覆盖。默认 `HOST=0.0.0.0`、端口5189。依赖在仓库根使用 `npm ci` 安装。

## 当前规则

- 新会话使用普通话数字1—9固定录音；每段随机种子生成完整序列，约28%合法项为2-back目标；非目标排除意外匹配。
- 每段前两项不评分。相同按鼠标左键或空格，不同不操作。每个数字录音固定500ms，音频窗可增加静默但不会截断发音，反应持续至下一刺激计划起点；鼠标事件使用 pointerdown，空格使用 keydown，长按及重复输入不改变首次有效响应。
- Mock模式由电脑右上角卡片模拟，真机模式发送原始PNG至眼镜双眼，显示时长从会话配置读取、不能按键提前关闭；数字播放不暂停、不重置，通知前后的2-back记忆连续保留。数字音频由被试电脑播放，眼镜无数字音频。
- 通知任务：连续听觉数字（前／中／后）→ 文本复述 → 四选一理解题 → 通用努力 → 恢复努力 → 休息。复述允许空白，理解题和评分必答、无预选；正式部分不反馈正误。
- 控制任务：相同数字试次数和虚拟通知窗口，无通知卡片／复述／理解题／恢复努力题，只有通用努力。练习有上一项对错反馈，无问卷。
- 努力评分统一1—9点。每次问题呈现与提交的浏览器时钟单独记录。
- 正式默认：12 个 Trial，其中 10 个通知＋2 个对照，另有练习。N1/N2/N3 按 3/3/4、3/4/3、4/3/3 跨被试轮换，N 水平交错，对照位置平衡；每个 N 水平从 6 条材料中抽取，同一被试内不重复。材料记录 ID、N 水平与业务类别，N 编码沿用来源。
- 后台可编辑通知时长、SOA、音频窗、Pre/Post 长度和 Post 恢复早窗，创建后冻结于会话计划快照。界面默认沿用4000ms通知，其余显示为2000/500/24000/20000/10000 ms；8500ms通知仅列候选，不表示研究参数已经冻结；可按 Pilot 比较 1500 ms 与 2000 ms SOA。
- 生成完整计划后按 N 水平和阶段检查目标数、非目标数、目标比例与位置分布，保留冻结的检查/再生成规则及警告。后台可在创建前预览计划，并在会话详情查看材料 N 单元标签、编码答案和来源差异。
- 快速预演只用于操作检查；其具体时间和序列以创建前预览与会话计划为准。休息可以提前结束。
- Post 可分为早期和后期；阶段以实际呈现时间戳判断，跨越通知出现/消失边界的刺激单独标记。通知时长无需为 SOA 整数倍。Trial总时长按Pre＋通知＋Post截止；最后不足完整SOA的反应窗口标记partial并排除评分。

## 数据与恢复

SQLite保存快照、尝试、只追加事件。浏览器先将事件保存到localStorage，再每500ms批量上传；断网不抛弃已有队列，网络重试按event_id和完整内容去重。页面的控制owner防止另一页面接管同一尝试。

任务中刷新不会自动续播；需主试中断后重跑，原尝试标invalid并保留，新运行有新的attempt_id。失焦、切后台或明显时序异常保留原始事件，摘要排除相应尝试，不能算作被试答错。任务内普通暂停没有实现，中断会使本次尝试无效。

导出含 events.jsonl、primary_items.csv、summary.csv、accuracy_changes.csv、pooled_summary.csv、pooled_changes.csv、sequence_balance.csv、full_trial_plan.csv、answers.csv、notifications.csv、materials.json、plan.json、session_qc.json、manifest.json。后台显示单次尝试表现和“被试×N 水平×阶段”合并表现。合并表先汇总全部有效刺激的命中、漏报、误报和正确拒绝计数，再计算准确率、命中率、误报率、平衡正确率；不平均各 Trial 的百分比。提供各指标有效分母及命中 RT 的均值、中位数与样本数。无目标时命中率为空，无正确命中时命中 RT 为空，不填 0。变化表含 Pre→During、Pre→Post 早期和 Pre→Post 后期比较。accuracy_changes另存正确率下降百分点及相对下降率(pre-window)/pre；pre为0或缺数据时相对值留空，表现提高保留负下降值，不截为0。原始事件保留源时间。Mock时间来自浏览器模拟呈现；真机另导出device_requests.json和设备绘制/隐藏事件。真机任务开始前与结束后各采集 7 个样本，经浏览器 HTTP 与眼镜 USB 往返进行软件时钟校准，检查前后映射一致性和误差，保存原始样本与验证结果。该校准不是光学呈现测量；映射缺失或未通过验证时，真实曝光窗口标记 unknown，不以请求时间计算未经验证的通知期间表现。详见 [设备说明](DEVICE.md)。
