## 运行

仓库根目录执行 `npm start`，打开 `http://127.0.0.1:5189/admin`。后台创建会话后点击“在本机打开被试页面”。主试手机可扫描顶部二维码，电脑运行被试任务。被试任务需要至少1000×600的电脑窗口。

运行目录默认 `a1-notification-pilot/runtime/`，ZIP 落盘到 `a1-notification-pilot/exports/`；可通过 `A1_RUNTIME_DIR`、`A1_EXPORT_DIR` 覆盖。默认 `HOST=0.0.0.0`、端口5189。依赖在仓库根使用 `npm ci` 安装。

## 当前规则

- 使用8个大写字母 B/C/D/F/G/H/J/K；每段随机种子生成完整序列，约28%合法项为2-back目标；非目标排除意外匹配，连续相同字母不超过3个。
- 每段前两项不评分。相同按鼠标左键或空格，不同不操作。刺激显示500ms，反应持续至下一刺激计划起点；鼠标事件使用 pointerdown，空格使用 keydown，长按及重复输入不改变首次有效响应。
- Mock模式由电脑右上角卡片模拟，真机模式发送原始PNG至眼镜双眼，固定4秒、不能按键提前关闭；字母不暂停、不重置，通知前后的2-back记忆连续保留。页面不会播放声音。
- 通知任务：连续字母（前／中／后）→ 文本复述 → 四选一理解题 → 通用努力 → 恢复努力 → 休息。复述允许空白，理解题和评分必答、无预选；正式部分不反馈正误。
- 控制任务：相同字母试次数和虚拟通知窗口，无通知卡片／复述／理解题／恢复努力题，只有通用努力。练习有上一项对错反馈，无问卷。
- 努力评分统一1—9点。每次问题呈现与提交的浏览器时钟单独记录。
- 快速预演：8项练习、1通知任务、1控制任务，SOA1200ms，休息3秒。通知和对照各16项，其中基线6项；这套缩短参数只为操作预览。
- 全部材料：18项练习、18通知＋2控制，3轮每轮6条。也可选择12条子集，每轮从同一N水平取4条，不强制领域配额。每任务基线22项、通知窗口2项、恢复18项，SOA2000ms，通知4秒。练习休息30秒，任务间休息60秒，可提前结束。
- 第1/2/3轮暂固定对应N1/2/3，轮内按种子随机；每次计划内材料不重复。正式被试间顺序平衡尚未实现，N编码沿用来源而不是程序重算的IU评分。

## 数据与恢复

SQLite保存快照、尝试、只追加事件。浏览器先将事件保存到localStorage，再每500ms批量上传；断网不抛弃已有队列，网络重试按event_id和完整内容去重。页面的控制owner防止另一页面接管同一尝试。

任务中刷新不会自动续播；需主试中断后重跑，原尝试标invalid并保留，新运行有新的attempt_id。失焦、切后台或明显时序异常保留原始事件，摘要排除相应尝试，不能算作被试答错。任务内普通暂停没有实现，中断会使本次尝试无效。

导出含events.jsonl、primary_items.csv、summary.csv、accuracy_changes.csv、answers.csv、notifications.csv、materials.json、plan.json、session_qc.json、manifest.json。后台显示前／中／后正确率、命中RT、相对前窗的百分点变化。accuracy_changes另存正确率下降百分点及相对下降率(pre-window)/pre；pre为0或缺数据时相对值留空，表现提高保留负下降值，不截为0。原始事件保留源时间。Mock时间来自浏览器模拟呈现；真机另导出device_requests.json和设备绘制/隐藏事件。真机与浏览器时钟映射尚未完成，真实曝光前／中／后窗口标记unknown，不伪用请求时间计算通知效应。详见 [设备说明](DEVICE.md)。
