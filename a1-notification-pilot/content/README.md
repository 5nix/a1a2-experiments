## 导入

在仓库根运行：

```sh
python3 a1-notification-pilot/scripts/import-materials.py
```

脚本仅用Python标准库，在写入前核对CSV标题、18个唯一编号、N1/N2/N3各6条、N单元和答案、图片一一对应关系。忽略ZIP的 `.DS_Store`、`__MACOSX` 等系统文件，清理不在新库中的运行卡片。题干、选项顺序、正确答案、N标签和正文均保留CSV原值。

CSV的正文没有保留图片折行，因此 `text_lines` 只保留显式换行，`line_count` 保留表格声明；模拟端和雷鸟均直接显示原PNG，保持图片原有折行和宽高比，不根据文件名或正文重新推断排版。`3N-2L-01/03/04` 的表格声明为1行，按此记录。

6条N3材料的来源字符数与实际正文计数不同，分别保存为 `character_count` 和 `character_count_computed`，清单逐项记录；不自动修订来源。原来的N1/N3/N4标签问题在新表已改为N1/N2/N3，不再保留旧问题标记。
