## 导入规则

在仓库根执行 `python3 a1-notification-pilot/scripts/import-materials.py` 可重新从这两份归档生成JSON和图片。脚本只依赖Python标准库。更新材料后重启服务并创建新会话，已有会话使用快照。

当前库共18条，N1/N2/N3各6条，分别为1行/1行/2行。类别以表格原值保留，不套用原SOP的四领域配额，也不把N编码自动改称IU。

导入直接遍历XLSX的sheetData：来源文件工作表的dimension错误地标为A1，使用该范围会只读到一个标题。Excel时间选项17:40和17:20从日小数恢复为HH:MM。正文的显式换行、来源标题、选项顺序、A—D答案均保留；字符数同时保存来源值和独立计算值。

`3N-2L-05`的三项编码标签原为N1/N3/N4。原值保留在n_units，source_warnings标记source_unit_labels_nonsequential；不自动改标签、不凭此重新推断N数或正确答案。

## 程序编排和呈现

后台默认提供“全部材料”：练习＋18通知＋2对照。按N水平分3轮，每轮6条顺序由种子随机；第1、2轮后各1个无通知对照。N水平暂时随轮次递增，不代表已完成顺序平衡。

另有快速预演（1通知＋1对照）和12条子集（各N水平随机取4条＋2对照）。子集不承诺四领域平衡，不擅自新增或改写来源材料。

Mock使用来源PNG，黑色底板显示其透明度和白色文字，保持原始宽高比。任务开始前读取并解码，图片SHA-256与会话快照核对；图片只对当前有权限的通知任务提供。旧版会话没有原图时继续使用原文字呈现，不重新分配新材料。

2-back继续运行；通知固定4秒，不支持按鼠标/空格关闭。模拟卡片不是雷鸟真机呈现，图片的屏幕缩放也不等于眼镜视觉角度标定。A1安卓端直接显示原始PNG，双眼黑底居中，宽284px并保持宽高比；尚需实际佩戴确认大小和清晰度，见 [设备说明](../DEVICE.md)。

逐刺激数据增加material_id、n_count、line_count、character_count、domain、material_version；通知事件增加原图编号；ZIP增加materials.json，并在计划快照保存完整问题/答案、来源行及原图哈希。

来源提取、编号匹配、类型/语法与差异检查已完成。后续设备链路9项模拟检查、Android构建和lint通过；未完成物理真机验收。
